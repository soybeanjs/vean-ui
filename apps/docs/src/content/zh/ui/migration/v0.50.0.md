# 升级指南：v0.40.0 → v0.50.0

v0.50.0 是一次引擎级重构发布：**日期、Table、Form 三大引擎整体更换**，Sheet/Drawer 家族按语义更名，headless 层收缩掉纯展示家族。0.x 阶段的 minor 允许 breaking，本次不提供旧 API 兼容层——以下逐条给出迁移对照。

| 你最先想知道的三件事                                                       |
| -------------------------------------------------------------------------- |
| 1. 日期值模型改为原生 `Date`，`CalendarDate` / `ZonedDateTime` 不复存在    |
| 2. Table 列与状态面以 TanStack 命名为第一公民，旧字段**不保留别名**        |
| 3. 只用 `@vean/ui`（`S` 组件）且不碰日期/表格/表单的项目，只需处理更名部分 |

## 1. 日期引擎：`@internationalized/date` → `date-fns` + `Date`

`@internationalized/date` 与 `@internationalized/number` 已被 `date-fns` + 平台 `Intl` API 替换。公开值模型改为原生 `Date`，组件 props/slots 面保持兼容，仅值类型换型；首个版本只支持**本地日期**（`ZonedDateTime`、非公历日历、`timeZoneName` 分段移除，`hideTimeZone` 保留一个版本周期作为 no-op）。

| v0.40.x                                    | v0.50.0                                        |
| ------------------------------------------ | ---------------------------------------------- |
| `CalendarDate`（日历日）                   | 本地 00:00 的 `Date`                           |
| `CalendarDateTime`（日期 + 时间）          | `{ date: Date, time?: Date }`                  |
| `Time`（一天中的时间）                     | `Date`（仅时分秒有意义，归一化到固定本地纪元） |
| `DateRange` / `TimeRange` `{ start, end }` | `{ start: Date \| null, end: Date \| null }`   |
| `DateMatcher` / `TimeMatcher`              | `(date: Date) => boolean` 谓词函数             |

```diff
- import { CalendarDate, CalendarDateTime, Time } from '@internationalized/date';
- const day = new CalendarDate(2026, 4, 19);
- const time = new Time(9, 30);
+ import { createDate, createTime } from '@vean/aria/date';
+ const day = createDate(2026, 4, 19); // 本地零点，月份 1 起始
+ const time = createTime(9, 30);
```

导出的类型名（`DateValue`、`DateRange`、`TimeValue`……）不变，只是形状换成了 `Date`。日历运算改用 `date-fns` 函数（`addDays` / `addMonths`…）或 `@vean/aria/date` 的内核助手（`setSegmentParts` / `cycleSegment` / `toISODateString`），数字格式化改用 `shared` 的 `createNumberFormatter` / `createNumberParser`（`Intl.NumberFormat` 薄包装）。

```bash
pnpm remove @internationalized/date @internationalized/number
pnpm add date-fns
```

完整的运算 / 格式化 / 解析对照见独立指南：**[日期引擎迁移](/overview/migration/v0.50.0-date)**。

## 2. Table 引擎：`@tanstack/vue-table`

自研列模型（排序 / 筛选 / 展开 / pin / size）已更换为 [`@tanstack/vue-table`](https://tanstack.com/table) v9。TanStack 命名是第一公民，旧字段**不保留别名**（深化的设计决策），需要按下表手动重命名：

| v0.4x（旧）                               | v0.50.0（TanStack）                                                |
| ----------------------------------------- | ------------------------------------------------------------------ |
| `{ title, dataIndex }`                    | `{ header, accessorKey }`                                          |
| `sorter: true` / `sorter(a, b)`           | `enableSorting: true` / `sortFn: (rowA, rowB) => number`           |
| `filter: true` / `filter: { ... }`        | `enableColumnFilter: true` / `filterPlaceholder` / `filterOptions` |
| `width: '140px'` / `minWidth`             | `size: 140` / `minSize`（px 数值）                                 |
| 分组列 `{ key, children }`                | `{ id, columns }`                                                  |
| `sortState` / `defaultSortState`          | `sorting` / `defaultSorting`（`SortingState`）                     |
| `filterState` / `defaultFilterState`      | `columnFilters` / `defaultColumnFilters`（`ColumnFiltersState`）   |
| `columnWidths` / `defaultColumnWidths`    | `columnSizing` / `defaultColumnSizing`（`Record<string, number>`） |
| `expanded: R[]`                           | `expanded: ExpandedState`（`{ '1': true }` 或 `true`）             |
| `update:sortState` / `update:filterState` | `update:sorting` / `update:columnFilters`                          |

```diff
  const columns = [
-   { title: 'Name', dataIndex: 'name', sorter: true, width: '180px' },
+   { header: 'Name', accessorKey: 'name', enableSorting: true, size: 180 }
  ];
- const expanded = ref([1]);
+ const expanded = ref({ 1: true });
```

引擎实例没有藏起来：插槽 props 携带 `table` / `engineColumn`，子树可用 `useTableEngine()`，模板 ref 直接暴露引擎（`tableRef.value.previousPage()`），高级 TanStack 选项经 `tableOptions` 透传。

完整的字段映射与示例见 [Table 文档「从 v0.4x 迁移」](/components/table)。

## 3. Form 引擎：`@tanstack/vue-form`

自研 `useHeadlessForm` 已更换为 [`@tanstack/vue-form`](https://tanstack.com/form)。**组件面不变**——`SForm` / `SFormField` / `SFormFieldArray` / `SFormFieldBase` 与 label/description/error、`aria-invalid` / `aria-describedby` 接线全部照旧；变化集中在钩子面：

| v0.4x                                          | v0.50.0                                                                                    |
| ---------------------------------------------- | ------------------------------------------------------------------------------------------ |
| `useForm(options, Field, FieldArray)` 返回元组 | `useForm(options)` 返回上下文对象（`handleSubmit`、`SFormField`、`isSubmitting`、`form`…） |
| `initialValues`                                | `defaultValues`（对齐 TanStack 命名）                                                      |
| `onSubmit(values, helper)`                     | `onSubmit(values)`（`FormSubmitHelper` 移除）                                              |
| `formState.values` / `errors` 等 `state` 快照  | `form.useSelector(state => …)` / `form.Subscribe`（原始 `form.state` 仍在 `FormApi` 上）   |
| `reValidateMode` / 字段级 `reset` 回调         | 移除——实时校验设 `validateMode: 'change'`，重置恢复 `defaultValues`                        |
| 数组嵌套路径 `social.0.name`                   | TanStack 规范格式 `social[0].name`（错误路径同样用方括号）                                 |

校验直接传 Standard Schema 对象（Zod / Valibot 均可），`@standard-schema/spec` 不再是本库的直接依赖，由你自己的校验库提供。字段级 `validate` 接受函数或 Standard Schema 校验器，经 Ref 传入可响应式换规则。

完整的钩子面对照与注意事项（数组错误路径、`_form` 键、`formOptions` 透传等）见 [Form 文档「从 v0.4x 迁移」](/components/form)。

## 4. NavigationMenu 移除

`SNavigationMenu` 与整个 `navigation-menu` 家族（headless 子路径、headless 根导出、`Headless.*` 命名空间、registry 项）已移除，唯一导航菜单家族为 `nav-menu`：

```diff
- import { SNavigationMenu } from '@vean/ui';
+ import { SNavMenu } from '@vean/ui';

- import { NavigationMenuRoot } from '@vean/aria/navigation-menu';
+ import { NavMenuRoot } from '@vean/aria/nav-menu';
```

Root props 基本同构；子菜单浮层从「指示器 + 视口」改为条目旁嵌套浮层（`NavMenuSubTrigger` / `NavMenuSubContent`），挂载控制从 `unmountOnHide` 改为内容原语上的 `forceMount`。完整映射见[迁移说明页](/components/navigation-menu)（保留一个版本周期）与 [NavMenu 文档](/components/nav-menu)。

## 5. Sheet / Drawer 更名

两个家族按语义互换名称，**行为归属更清晰**：侧边面板叫 Sheet，手势抽屉叫 Drawer。

**`SDrawer`（侧边面板）→ `SSheet`**——compose Dialog 原语不变，行为完全一致，纯改名：

| 旧名                                          | 新名                                       |
| --------------------------------------------- | ------------------------------------------ |
| `SDrawer`                                     | `SSheet`                                   |
| `drawerVariants`                              | `sheetVariants`                            |
| `DrawerProps` / `DrawerEmits` / `DrawerSlots` | `SheetProps` / `SheetEmits` / `SheetSlots` |

**`SBottomSheet`（手势抽屉）→ `SDrawer`**——家族整体更名，同时内核按 Base UI 模型重构：

| 旧名                                      | 新名                                                                                  |
| ----------------------------------------- | ------------------------------------------------------------------------------------- |
| `SBottomSheet` / `BottomSheetRoot` / `…`  | `SDrawer` / `DrawerRoot` / `…`（前缀逐一对应）                                        |
| `@vean/aria/bottom-sheet`                 | `@vean/aria/drawer`                                                                   |
| `v-model:active-snap-point`               | `v-model:snap-point`                                                                  |
| `direction` prop（headless）              | `side` prop                                                                           |
| `data-vean-bottom-sheet-*`                | `data-vean-drawer-*`                                                                  |
| `shouldScaleBackground` / `fadeFromIndex` | 移除——用 `DrawerIndent` + `DrawerIndentBackground` 包裹页面；遮罩透明度随滑动连续衰减 |

```diff
- <SBottomSheet v-model:open="open" v-model:active-snap-point="snap" :snap-points="[0.5, 1]">
+ <SDrawer v-model:open="open" v-model:snap-point="snap" :snap-points="[0.5, 1]">
    <template #trigger><SButton>打开</SButton></template>
    内容
- </SBottomSheet>
+ </SDrawer>
```

注意 `snapPoint` 默认值从 `null` 变为 `snapPoints` 第一项（打开即定位在吸附点上）。更名与引擎细节见 [Sheet 文档](/components/sheet)与 [Drawer 文档](/components/drawer)。

## 6. headless 解剖壳收缩（只用 UI 层可跳过）

纯展示家族已从 headless 移除，**`@vean/ui` 的组件名全部保留**——只有直接 import headless 原语的项目受影响：

| headless 子路径（已移除） | 迁移方式                                                                             |
| ------------------------- | ------------------------------------------------------------------------------------ |
| `@vean/aria/card`         | `SCard` 保留（现基于 `CollapsibleRoot` 组合，默认展开，recipe 与 `ui` 覆盖语义不变） |
| `@vean/aria/empty`        | `SEmpty` 保留（UI-only 实现）                                                        |
| `@vean/aria/list`         | 无对应 S 组件——纯列表用 `ul/li` + UI class，交互列表走 `listbox` / `tree`            |
| `@vean/aria/skeleton`     | `SSkeleton` 保留（UI-only 实现）                                                     |
| `@vean/aria/badge`        | `SBadge` 保留（UI-only 实现，可关闭能力组合 Button/Icon）                            |
| `@vean/aria/tag`          | `STag` 保留（UI-only 实现）；可关闭标签交互以 `tags-input` 为准                      |

`Alert` 家族保留 headless，并为语义补齐 `role?: 'alert' | 'status'`（默认 `'alert'`，live region 由 ARIA 隐式承担）——这是新增能力，不是 breaking。

## 7. `SPopper` / `SArrow` 不再从 UI 包导出

UI 层的零样式转发已停止公开——`SPopper` 基于 headless `PopperCompact` 加样式配方，`SArrow` 直转 headless `Arrow`。公开样式面由 popover / tooltip / hover-card 承担：

```diff
- import { SPopper, SArrow } from '@vean/ui';
+ import { PopperCompact } from '@vean/aria/popper'; // 无样式装配，定位样式需自行承担
+ import { Arrow } from '@vean/aria/arrow';
```

## 8. 依赖变化

headless 运行时依赖按「引擎级能力才保留第三方」的白名单收缩：

```bash
# 已移除（曾以传递依赖形式出现在你的 lockfile 中）
@dnd-kit/dom            # PageTabs 排序改自研 useSortableList
@dnd-kit/vue
@formkit/auto-animate   # 动画改自研 collapseMotion 状态驱动方案
@internationalized/date # 见第 1 节
@internationalized/number
@standard-schema/spec   # 校验库由你自带（Zod / Valibot）

# 新增
date-fns                # 日期引擎
@tanstack/vue-table     # Table 引擎
@tanstack/vue-form      # Form 引擎
```

如果此前的代码靠 pnpm 提升直接 import 过这些被移除的包，请把它们显式声明进自己的 `package.json`。date-fns 建议按子路径导入（`date-fns/addDays`），在不具备 sideEffects 感知能力的构建环境里只加载用到的函数。

tree-shake 方面：`import { SButton } from '@vean/ui'` 的产物断言不含 table / form / date-fns / embla 代码（bundle fixture 已进 CI），headless / ui 的运行时依赖白名单由 `pnpm check:deps` 门禁把守。

## 9. `SPagination`：`actionAsSelected` → `actionVariant`

让 first/prev/next/last 操作按钮复用列表项样式的开关更名为 `actionVariant`；语义与默认值（`false`）不变，选中页码的 `variant` 样式在开关任意取值下都照旧生效：

```diff
- <SPagination variant="solid" action-as-selected :total="200" />
+ <SPagination variant="solid" action-variant :total="200" />
```

样式属性本身（`variant` / `shape` / `size`）不受影响，配方仍只在开关开启时把 variant 应用到操作按钮。当前属性表见 [Pagination 文档](/components/pagination)。

## 这次能拿到什么

- **Drawer 手势内核重构**（Base UI 模型）：CSS 变量驱动的 transform、snap point 值模型、原生触摸管线（触摸/滚动仲裁、滚动边缘起滑）、`DrawerIndent` 原语与嵌套协调。
- **动画自研化**：PageTabs 排序的 `useSortableList`（FLIP 换位 + 键盘排序）、form 错误与 tree 展开的 `collapseMotion` 高度塌缩动画。
- **Table 引擎逃生舱**：`useTableEngine()` 注入、`tableOptions` 全量透传、插槽 props 携带引擎实例。
- **Form 表达力**：`UseFormOptions` 双推理源泛型（schema 缺省时由 `defaultValues` 推导）、字段 `validate` 支持 Standard Schema 对象与响应式 rebinding。
- **补公开导出**：`InputNumberClear`、`LayoutPlaceholder`、`MenubarMenus`、`NavMenuOptionCompact`、`TableCompactHead` / `TableCompactRow` / `TableVirtualSpacerRow`。
- **A11y**：Alert 的 `role="alert" | "status"` 语义、浮层背景 inert 标记（上一版本已就位的 `markOthers` 继续承接）。
- **CI 质量门禁**：bundle fixture（摇树断言）+ 依赖白名单/黑名单检查（`pnpm check:deps`）。
- CLI 目录迁移至 `packages/cli`；品牌改名后包名为 `@vean/cli`、bin 为 `vean`（见下方品牌迁移指南）。

## 品牌改名与本次发布同步落地

品牌级改名（SoybeanUI → Vean：npm scope 切换、`@soybeanjs/headless` → `@vean/aria`、`data-soybean-*` → `data-vean-*`、`--soybean-*` → `--vean-*`、`sbean` CLI → `@vean/cli`）与本轮引擎重构落在同一窗口发布，因此你**只需要迁移一次**。一键改写：`npx @vean/cli@latest migrate rebrand --write`；包名映射、运行时契约改名、Nuxt/UnoCSS 配置与 CLI 迁移步骤见独立指南：**[升级指南：SoybeanUI → Vean](/overview/migration/rebrand)**。

不变项：组件前缀 `S`（= Styled）、设计令牌 `--primary` / `--size` / `--radius`、以及 `@soybeanjs/cva` / `@soybeanjs/colord`。主题改为单个 `localStorage` 信封（`__VEAN_THEME`，见[主题指南](/overview/theming)），旧的 `__SOYBEAN_THEME*` 键不再读取。

## 升级检查清单

1. `pnpm remove @internationalized/date @internationalized/number && pnpm add date-fns`；日期值改用 `Date` / `createDate` / `createTime` 构造。
2. Table 列定义与状态面改 TanStack 形状（`accessorKey` / `sorting` / `columnFilters` / `ExpandedState`…），旧字段无别名。
3. Form 的 `useForm` 迁移到上下文对象返回面，`initialValues` → `defaultValues`。
4. `SNavigationMenu` → `SNavMenu`（headless 同步 `NavMenu*`）。
5. `SDrawer` → `SSheet`；`SBottomSheet` → `SDrawer`（`v-model:active-snap-point` → `v-model:snap-point`，scale background 改 `DrawerIndent`）。
6. 直接使用 headless `card` / `empty` / `list` / `skeleton` / `badge` / `tag` 的引用改为 UI 组件或自行组合。
7. `SPopper` 改用 `PopperCompact`（或迁移到 popover / tooltip / hover-card），`SArrow` 改从 `@vean/aria/arrow` 导入。
8. 曾靠依赖提升使用的移除包，显式声明进自己的 `package.json`。
9. `SPagination` 的 `actionAsSelected` 属性改为 `actionVariant`（`:action-as-selected` → `:action-variant`）。
10. `pnpm typecheck` 与构建通过后，重点回归日期选择、表格排序筛选、表单校验与抽屉手势四类交互。
