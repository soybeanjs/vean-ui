## 归档规则

- **何时进本目录**：内容描述一段已完成的工作 / 一次评估 / 一份快照，之后**不会持续更新**。
- **何时不进**：需要持续维护的真相源（架构 / 方案 / 状态）进对应目录，不放 `info/`。
- 可带日期后缀命名（`<name>-YYYY-MM-DD.md`）以区分批次；默认沿用 `kebab-case`。
- 归档时在「最近更新」或提交信息中注明去向，避免读者找不到原位置。
