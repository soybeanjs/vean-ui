## 新建 ADR 流程

1. 确定决策影响面足够大（分层 / 命名 / 许可 / 依赖方向 / 不可逆发布决策）。
2. 复制下方模板，编号取**当前最大序号 + 1**（四位左对齐补零，如 `0002-`）。
3. 填写：状态（`proposed` → `accepted` / `rejected` / `superseded`）、背景、决策、权衡（含被拒方案）、后果、相关。
4. 在本索引表登记一行，并链接关联文档。
5. 提交信息：`docs(adr): add ADR-NNNN <标题>`。

## 模板

```markdown
# ADR-NNNN: <标题>

## 状态

proposed / accepted / rejected / superseded

## 背景

<为什么需要这个决策：现状、矛盾、触发因素>

## 决策

<我们决定怎么做，编号列出>

## 权衡

<对比被拒绝的方案；说明代价与理由>

## 后果

<决策落地后的影响、义务、不可逆点>

## 相关

- <关联文档链接>
```
